# UI_UX.md

## Design direction
Original premium UK courier brand:
- clean
- fast
- trustworthy
- operational
- modern
- strong CTA hierarchy

Do not clone Dash Delivery's exact visual identity.

## Palette
Use CSS variables.
Suggested:
- deep navy
- courier blue
- white/light neutral
- charcoal
- success green
- warning amber
- danger red

## Typography
Readable modern sans-serif.
UK English copy.
Ready for additional languages.

## Components
Navbar, hero, tracking box, quote wizard, service cards, pricing breakdown, status badge, timeline, KPI cards, data tables, filters, modal, drawer, toast, empty/error/loading states, invoice preview.

## Responsive
Test 360, 390, 768, 1024 and 1440px.

## Admin
Desktop sidebar + topbar.
Mobile collapsible navigation and responsive tables/cards.

## Quote wizard
Step 1 Route
Step 2 Parcel
Step 3 Service
Step 4 Price
Step 5 Confirm

Server recalculates every total.

## Invoice
A4-style preview with View, Print, Download PDF, Send and Record Payment.

## Accessibility
WCAG 2.2 AA-oriented.
Keyboard navigation, labels, visible focus, semantic headings, accessible dialogs and no color-only statuses.
