# UK Delivery Platform — Antigravity Development Pack

Production specification for an original UK courier/logistics platform inspired by the public functional structure of Dash Delivery.

## Stack
- PHP 8.2+ / 8.3 preferred
- MySQL 8.x / MariaDB-compatible SQL where practical
- HTML5, CSS3, JavaScript
- Bootstrap 5 or custom component system
- Leaflet + OpenStreetMap for maps
- PDO prepared statements
- Hostinger Business hosting
- Apache/LiteSpeed-compatible deployment
- No Node.js server required in production
